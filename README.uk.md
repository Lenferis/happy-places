## Що це

Це самостійний шаблон для подарункового фотоальбому. Ви відкриваєте сторінку — на столі лежить закрита книга у шкіряній палітурці. Торкаєтесь — обкладинка розкривається, камера підлітає, і починається подорож сторінками.

Кожна сторінка може містити:

- одне велике фото, два, три або сітку з чотирьох;
- «живий» стос фотографій, які падають одна на одну при перегортанні;
- рукописний лист із рядками, як у зошиті;
- 3D-попапи, які «виростають» зі сторінки при відкритті;
- декор: стрічки-скотч, квіти, штампи, серця, іскри;
- голосове повідомлення з програвачем і хвильовою дорожкою, яку можна перемотати;
- відео, яке програється прямо на сторінці.

Усе це — HTML-файл + папка з модулями. **Без збірки, без Node.js, без npm.** Достатньо локального вебсервера.

## Можливості

| | |
|---|---|
| **Анімована обкладинка** | Корешок розчиняється при відкритті, обкладинка плавно перегортається |
| **Реалістичне перегортання** | Вершинний шейдер гне лист по дузі, край закручується |
| **Перетягування кута** | Можна тягнути сторінку пальцем/мишею, як справжню |
| **Фото, відео, декор** | Полароїди, рамки, кутники, штампи |
| **Стоси фото** | Фото падають по одному при кожному гортанні вперед |
| **Живий декор** | Пелюстки летять, пил світиться |
| **Голосові повідомлення** | Play/pause + перемотування по хвильовій дорожці |
| **Фонова музика** | З автоматичним приглушенням, коли звучить голос |
| **3D-попапи** | Окремі меші, що розкриваються разом зі сторінкою |
| **Мобільна адаптація** | Портретний/ландшафтний режим, safe-area, touch |
| **Reduced-motion** | Враховує `prefers-reduced-motion` |
| **Asset warnings** | Якщо чогось не вистачає — покаже, чого саме |

## Технології

| | |
|---|---|
| [Three.js 0.160](https://threejs.org/) | WebGL-рендер, шейдери, GLTF, OrbitControls |
| Native ES modules + importmap | Без збірки, без бандлера |
| Canvas 2D | Уся «поліграфія» сторінок (фони, рамки, текст, декор) |
| WebAudio API | Процедурні sfx (шелест, клік, стукіт) |
| HTMLAudio | Фонова музика + голосові повідомлення |
| Google Fonts | Cormorant (заголовки), Caveat (рукопис) |

> **Жодного build-кроку.** `index.html` відкриває `src/main.js`, той тягне решту через `import`. Усе як у 2015-му, тільки з importmap.

## Швидкий старт

### 1. Клонувати / скопіювати проєкт

```bash
git clone https://github.com/USER/happy-places.git
cd happy-places
```

Або просто розпакувати ZIP у будь-яку папку.

### 2. Запустити локальний сервер

ES-модулі **не працюють через `file://`**. Потрібен будь-який локальний сервер.

**Python (є всюди):**
```bash
python3 -m http.server 8000
```

**Node.js:**
```bash
npx serve .
# або
npx http-server -p 8000
```

**PHP:**
```bash
php -S localhost:8000
```

**VS Code:** розширення [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) → правий клік по `index.html` → **Open with Live Server**.

### 3. Відкрити в браузері

```
http://localhost:8000/
```

Побачите екран завантаження із трояндою, потім обкладинку. Торкніться — альбом відкриється.

## Налаштування альбому

### Структура папок з медіа

Проєкт шукає файли за фіксованими шляхами. Якщо у вас інша структура — змініть `src/config/paths.js`.

| Папка | Призначення | Формати |
|---|---|---|
| `imgs/` | Фото, відео для сторінок | `jpg`, `jpeg`, `png`, `webp`, `mp4`, `webm`, `mov` |
| `imgs/decor/` | Декор (квіти, пелюстки, гілки) | `png` (з прозорістю!), `webp`, `jpg` |
| `audio/` | Голосові повідомлення | `mp3`, `m4a`, `ogg`, `wav`, `aac`, `opus` |
| `models/` | GLB-моделі для 3D-попапів | `glb` |
| `music.mp3` | Фонова музика (один файл) | `mp3` |

> **Порада.** Використовуйте для декору **PNG з прозорістю** — інакше навколо квітки буде біла рамка. Для фото — `webp` або `jpg` (менше важать, швидше завантажуються).

### Додавання фото та відео

**Крок 1.** Покладіть файли в `imgs/`. Наприклад:

```
imgs/
├── morning.jpg
├── sea-2024.mp4
└── sunset.webp
```

**Крок 2.** Зареєструйте їх у `src/config/assets.js`:

```js
export const PHOTO_FILES = {
  morning:  'morning',      // ключ → ім'я файлу без розширення
  sea:      'sea-2024',
  sunset:   'sunset'
};
```

Ключ (ліва частина) — це те, як ви посилаєтесь на файл у `PAGES`. Значення (права) — ім'я файлу без розширення. Розширення програма підбере сама зі списку `PHOTOS_IMAGE_EXTS` / `PHOTOS_VIDEO_EXTS`.

**Крок 3.** Використайте у `PAGES` (див. нижче).

**Крок 4 (необов'язково).** Якщо хочете, щоб відео грало саме на сторінці — додайте `video: true`:

```js
{ type: 'photo', photos: [
  { img: 'sea', video: true, caption: 'Наше море' }
]}
```

Без цього тегу програма шукатиме спочатку картинку, і лише потім відео.

**Як альтернатива файлам** — можна вставити Base64 прямо в `assets.js`:

```js
export const ASSETS = {
  photos: {
    morning: 'data:image/jpeg;base64,/9j/4AAQSkZJRg...'
  }
};
```

Корисно, якщо не хочете тримати окремі файли (наприклад, для однієї обкладинки).

### Додавання декору

**Крок 1.** Покладіть PNG у `imgs/decor/`. Ім'я файлу без розширення буде ключем:

```
imgs/decor/rose.png       → ключ: "rose"
imgs/decor/peony.png      → ключ: "peony"
```

**Крок 2.** Зареєструйте в `src/config/assets.js` з «бажаним розміром за замовчуванням»:

```js
export const DECOR_FILES = {
  rose:    { file: 'rose',    size: 170 },
  peony:   { file: 'peony',   size: 170 },
  daisy:   { file: 'daisy',   size: 190 },  // ← ваш новий
  ribbon:  { file: 'ribbon',  size: 240 }
};
```

Параметр `size` — це ширина в пікселях канваса 1024×1312, якою декор буде намальовано **за замовчуванням**, якщо в `PAGES` не вказати `size` явно.

**Крок 3.** Використайте в `PAGES`:

```js
{ type: 'ditem', key: 'daisy', at: { x: 0.15, y: 0.80 }, size: 220, rot: -18 }
```

### Додавання музики та голосу

**Фонова музика.** Покладіть `music.mp3` у **корінь проєкту** (поруч з `index.html`). Усе.

**Голосові повідомлення.** Покладіть файл у `audio/` і додайте до сторінки декор типу `voice`:

```js
deco: [
  { type: 'voice',
    file: 'greeting',              // → audio/greeting.mp3
    at: { x: 0.5, y: 0.87 },
    size: 300,
    rot: -2,
    label: 'натисни — я це сказала вголос' }
]
```

Голос **не потрібно реєструвати** в `assets.js` — він сам знайдеться за іменем.

### Налаштування сцени

`src/config/scene.js` — усе про оточення. Основні параметри:

**Світло.** Кожне джерело можна вимкнути (`intensity: 0`), перемістити (`pos`), змінити колір:

```js
lights: {
  hemi: { sky: '#ffe2b8', ground: '#1c0f06', intensity: 0.85 },
  sun:  { color: '#ffd9a6', intensity: 2.6, pos: [2.3, 4.3, 2.7] },
  glow: { color: '#ffca8a', intensity: 0.5, pos: [0, 2.3, 0.7],
          distance: 6.5, decay: 1.6 }
}
```

> Щоб увімкнути **тіні** — поставте `sun.castShadow: true`. Тіні вимогливі до ресурсів (особливо на мобільних).

**Камера.** Дві позиції: `home` — закрита книга, `reading` — відкрита:

```js
camera: {
  home:    [2.3, 1.55, 3.45],   // стартова
  reading: [0.15, 2.35, 2.22],  // при читанні
  // ...і «цілі», куди дивиться камера (окремо для портретної орієнтації)
  homeTarget:            [0, 0.34],
  homeTargetPortrait:    [0, 0.20],
  readingTarget:         [0, 0.11],
  readingTargetPortrait: [0, 0.18]
}
```

**Стіл.** Тип, колір, розмір:

```js
table: { type: 'wood', color: '#2a1508', repeat: 3.2, size: 9 }
```

Доступні типи: `wood` (дерево), `linen` (лляне), `plain` (суцільний).

**Тканина під книгою.** Можна вимкнути (`enabled: false`) або змінити на лляну скатертину:

```js
cloth: { enabled: true, type: 'linen', color: '#e7d5b4',
         size: [3.9, 2.72], y: 0.004 }
```

**Пелюстки.** Падаючі квітки:

```js
particles: [
  {
    type: 'fall',                    // 'fall', 'rise', 'drift', 'float'
    textures: ['petal_1', 'petal_2', 'petal_3', 'petal_4'],
    count: 12,                       // скільки пелюсток
    size: 0.075,                     // розмір у метрах
    speed: [0.10, 0.20],             // діапазон швидкості падіння
    opacity: 0.85,
    area: { x: [-1.3, 1.3], y: [0.02, 2.7], z: [-0.8, 1.0] }
  }
]
```

**Пил.** Мерехтливі точки в повітрі. Можна вимкнути (`enabled: false`) або змінити щільність:

```js
dust: {
  enabled: true,
  count: 90,
  size: 0.045,
  color: 0xffe0b0,
  opacity: 0.5
}
```

## Довідник типів сторінок

Усі сторінки описані масивом `PAGES` у `src/config/album.js`. Сторінки йдуть **парами** — ліва, права, ліва, права... Тому кількість має бути парною.

### `title` — титул

Перша сторінка після обкладинки. Використовує `TITLE_PAGE` зверху файлу.

```js
{ type: 'title' }
```

### `photo` — фото-сторінка

Найпоширеніший тип. Може містити від 1 до 4 фото.

**Одне фото на всю сторінку:**

```js
{
  type: 'photo',
  photos: [{
    img: 'morning',
    caption: 'Ранок, який починається з тебе',
    date: 'травень 2023',
    aspect: 16/9,       // співвідношення сторін
    tilt: 30.2,          // нахил у градусах
    frame: 'polaroid'    // рамка
  }],
  deco: [
    'tape',
    { type: 'ditem', key: 'rose', at: { x: 0.86, y: 0.79 }, size: 200, rot: -25 }
  ],
  text: [
    { content: 'ТРАВЕНЬ', at: { x: 0.5, y: 0.06 }, anchor: 'c',
      font: '600 36px Cormorant, serif', fill: '#8a5a2b' }
  ]
}
```

**Два фото** (лейаут `duo`):

```js
{
  type: 'photo',
  layout: 'duo',
  photos: [
    { img: 'sea',  caption: 'Море',  frame: 'polaroid' },
    { img: 'field', caption: 'Поле', frame: 'none' }
  ]
}
```

**Три фото** (`trio`) і **чотири** (`grid`) — так само, з `layout`.

> Якщо `layout` не вказано — програма підбере автоматично: 1 → `single`, 2 → `duo`, 3 → `trio`, 4 → `grid`.

### `stack` — стос фото

Фото лежать одне на одному. При кожному гортанні вперед — верхнє падає на стос. Назад — фото повертається.

```js
{
  type: 'stack',
  style: 'fall',           // 'fall', 'fan', 'sweep'
  photos: [
    { img: 'one', x: 0.50, y: 0.40, w: 0.55, rot: -6, aspect: 4/3, frame: 'polaroid' },
    { img: 'two', x: 0.55, y: 0.45, w: 0.52, rot:  5, aspect: 16/9 },
    { img: 'three', x: 0.47, y: 0.50, w: 0.53, rot: -3 },
    { img: 'four', x: 0.52, y: 0.55, w: 0.50, rot:  8, frame: 'rounded' }
  ]
}
```

| Поле | Опис |
|---|---|
| `x`, `y` | Позиція на сторінці в частках (0..1) |
| `w` | Ширина у частках ширини сторінки |
| `rot` | Нахил у градусах |
| `aspect` | Співвідношення сторін |
| `frame` | Тип рамки |

Стилі падіння:

| Стиль | Опис |
|---|---|
| `fall` | Падає зверху з невеликим випадковим зсувом |
| `fan` | Відлітає з центру сторінки, крутиться, приземляється |
| `sweep` | Пролітає збоку з низької дуги |

### `letter` — лист

Текст на сторінці, як у зошиті — з лінійками під кожним рядком.

```js
{
  type: 'letter',
  heading: 'Любе [Ім’я],',
  body: [
    'Коли я гортаю ці сторінки, я знову чую твій сміх...',
    'У кожному моменті — ти...'
  ],
  sign: '— твоя, назавжди'      // необов'язковий підпис
}
```

### `popup` — 3D-попапи

Спеціальний тип: елементи «виростають» зі сторінки при її відкритті. Кожен елемент — це `kind: 'photo' | 'ditem' | 'model'`.

```js
{
  type: 'popup',
  text: [
    { content: 'НАШІ МОМЕНТИ', at: { x: 0.5, y: 0.07 }, anchor: 'c',
      font: '600 56px Cormorant, serif', fill: '#8a5a2b' }
  ],
  elements: [
    { kind: 'photo', img: 'morning', at: { x: 0.26, y: 0.60 },
      w: 0.36, frame: 'polaroid', caption: 'Ранок' },
    { kind: 'photo', img: 'sea',     at: { x: 0.72, y: 0.60 },
      w: 0.36, frame: 'polaroid', caption: 'Море' },
    { kind: 'ditem', key: 'rose',    at: { x: 0.08, y: 0.95 }, size: 0.10 }
  ]
}
```

| Поле | Опис |
|---|---|
| `at.x`, `at.y` | Позиція точки «петлі», у частках (0..1) |
| `angle` | Кут розкриття в градусах (за замовчуванням 90) |
| `w` (для photo) | Ширина у частках сторінки |
| `size` (для ditem) | Ширина у частках сторінки |

### `closing` — фінальна

Остання сторінка. За замовчуванням береться `CLOSING_DEFAULTS`.

```js
{ type: 'closing' }
```

Можна перевизначити:

```js
{ type: 'closing',
  text: [
    { content: 'дякуємо\nза ці моменти',
      at: { x: 0.5, y: 0.676 }, anchor: 'c',
      font: 'italic 500 46px Cormorant, serif',
      fill: '#6b4a35', lineHeight: 63 }
  ]
}
```

## Довідник декору

Декор додається до будь-якої сторінки в масиві `deco`. Кожен елемент — це або рядок-скорочення (`'tape'`, `'corners'`), або об'єкт із полем `type`.

### Позиціювання

Є два способи вказати, де малювати декор:

**1. Через `at`** — абсолютні координати у частках сторінки:

```js
{ type: 'heart', at: { x: 0.5, y: 0.86 }, size: 44 }
```

**2. Через `photo` + `anchor` + `dx`/`dy`** — прив'язка до фото:

```js
{ type: 'ditem', key: 'rose', photo: 0, anchor: 'tr', dx: -10, dy: -6 }
```

`photo` — індекс фото в масиві (0, 1, 2...). `anchor` — точка на фото:

```
nw  n  ne
w   c   e
sw  s  se
```

`dx`, `dy` — зсув у пікселях від цієї точки.

### Загальні поля

| Поле | Опис |
|---|---|
| `type` | Тип декору |
| `at` | Абсолютна позиція `{ x, y }` (0..1) |
| `photo` | Індекс фото для прив'язки |
| `anchor` | Точка прив'язки |
| `dx`, `dy` | Зсув у пікселях |
| `size` | Розмір |
| `rot` | Обертання в градусах |
| `alpha` | Прозорість (0..1) |
| `behind` | `true` — малювати **під** фото |

### Типи

#### `ditem` — довільна картинка з `imgs/decor/`

```js
{ type: 'ditem', key: 'rose', at: { x: 0.5, y: 0.36 }, size: 416, rot: -25 }
```

| Поле | Опис |
|---|---|
| `key` | Ключ із `DECOR_FILES` |
| `src` | Прямий шлях до файлу (альтернатива `key`) |
| `tintMode` | `'foil'` (золото), `'replace'`, `'multiply'` |
| `tint` | Колір для `tintMode` |
| `goldShadow` | `true` — додати темну тінь під золотом |

#### `tape` — стрічка-скотч

Короткий запис: `'tape'` (звичайна) або `'tape2'` (золота).

```js
{ type: 'tape', photo: 0, at: { x: 0.27, y: 0.14 },
  size: 120, rot: -8, variant: 'gold' }
```

Без `at` — автоматично приклеюється зверху фото з двох боків.

#### `corners` — фотокутники

Короткий запис: `'corners'`.

```js
{ type: 'corners', photo: 0, behind: true, inset: -2 }
```

| Поле | Опис |
|---|---|
| `corners` | Масив `['tl','tr','bl','br']` — які кутники малювати |
| `inset` | Зсув назовні/всередину |

#### `heart` — серце

```js
{ type: 'heart', at: { x: 0.5, y: 0.86 }, size: 44, color: 'rgba(181,72,58,.85)' }
```

#### `clip` — скріпка

```js
{ type: 'clip', photo: 1, anchor: 't', dx: 0, dy: -28, rot: 6 }
```

#### `stamp` — круглий штамп

Короткий запис: `'stamp'` або `'stamp2'`.

```js
{ type: 'stamp', at: { x: 0.86, y: 0.16 }, rot: -14,
  lines: ['щастя', '2024'], size: 104 }
```

#### `star` / `sparkle` — зірки та іскри

```js
{ type: 'star',    at: { x: 0.16, y: 0.14 }, size: 46, color: 'rgba(184,138,57,.85)' }
{ type: 'sparkle', at: { x: 0.16, y: 0.14 }, size: 34, color: 'rgba(233,200,115,.9)' }
```

#### `underline` — хвилясте підкреслення

```js
{ type: 'underline', at: { x: 0.5, y: 0.78 }, size: 180, rot: -3,
  color: 'rgba(181,72,58,.75)' }
```

#### `line` — проста лінія

```js
{ type: 'line', at: { x: 0.5, y: 0.776 }, size: 280, width: 2,
  color: 'rgba(212,170,90,.65)' }
```

#### `text` — довільний текст

```js
{ type: 'text', content: 'ранок',
  photo: 0, anchor: 'bl', dx: 20, dy: -10,
  family: 'Caveat, cursive', size: 64, weight: 600,
  fill: 'rgba(58,36,24,.85)', rot: -6 }
```

#### `voice` — голосове повідомлення

```js
{ type: 'voice', file: 'greeting', at: { x: 0.5, y: 0.87 },
  size: 300, rot: -2, label: 'натисни — я сказала це вголос' }
```

| Поле | Опис |
|---|---|
| `file` | Ім'я файлу в `audio/` без розширення |
| `label` | Підпис під програвачем |
| `size` | Ширина програвача в пікселях канваса |

## Розгортання

Оскільки це статичний сайт без бекенду — підійде будь-який хостинг.

### GitHub Pages

```bash
# 1. Створити репозиторій і запушити код
git remote add origin git@github.com:USER/REPO.git
git branch -M main
git push -u origin main

# 2. У налаштуваннях репо: Settings → Pages → Source = "main" / "(root)"
```

Через хвилину буде доступно за адресою `https://USER.github.io/REPO/`.

> **Важливо.** Якщо сайт лежить у підпапці (`/REPO/`), а не в корені — переконайтеся, що всі шляхи в `src/config/paths.js` **відносні** (без `/` на початку). Усі шляхи проєкту вже такі, але варто перевірити.

### Netlify / Vercel

Перетягніть папку проєкту у веб-інтерфейс — і все. Або через CLI:

```bash
# Netlify
npx netlify-cli deploy --dir=.

# Vercel
npx vercel --prod
```

Build-команду залиште порожньою, публічна папка — `.` (корінь).

### Cloudflare Pages

Те саме: підключити Git-репозиторій, залишити всі налаштування за замовчуванням.

### Власний сервер (nginx)

Просто покладіть вміст проєкту в `/var/www/html/`:

```nginx
server {
  listen 80;
  root /var/www/happy-places;
  index index.html;
  location / { try_files $uri $uri/ /index.html; }
}
```

## Розв'язання проблем

### Білий екран, у консолі «Failed to load module script»

Ви відкрили через `file://`. ES-модулі вимагають `http://` або `https://`. Запустіть локальний сервер (див. [Швидкий старт](#швидкий-старт)).

### «doesn't provide an export named X»

У файлі, де має бути `X`, немає `export` перед відповідним `const`/`function`. Відкрийте файл і перевірте.

### «Cannot access 'X' before initialization»

Циклічний імпорт. Подивіться повний стек у консолі — там буде шлях модуля-винуватця.

### Екран завантаження висить вічно

Відкрийте DevTools → **Network** → перевірте, який файл у статусі pending / failed.

### Фото не з'являється

1. Перевірте, що файл лежить у `imgs/`.
2. Перевірте, що ім'я файлу в `PHOTO_FILES` збігається з реальним (без розширення).
3. Подивіться в **Console** — там буде `[album] Медіа не знайдено для ключа "..."`.
4. Подивіться в **AssetWarnings** (червона накладка зліва зверху) — там перелік усіх відсутніх ресурсів.

### Декор не з'являється

1. Перевірте, що файл у `imgs/decor/` і він **PNG з прозорістю**.
2. Перевірте `DECOR_FILES` — ключ та ім'я файлу.
3. У консолі: `[album] ditem "..." файл не знайдено у imgs/decor/`.

### Музика не грає

1. Перевірте, що `music.mp3` у **корені проєкту** (поруч з `index.html`).
2. Більшість браузерів блокують автозапуск звуку — потрібен перший клік/тап користувача. Доти кнопка звуку сіра.
3. Подивіться помилку в консолі: `[music] play rejected: ...`.

### Голосове не грає

1. Перевірте, що файл у `audio/`.
2. Перевірте підтримку формату — `mp3` працює всюди, `m4a` — майже всюди, `opus` — тільки в Chrome/Firefox.
3. `[album] voice "..." не знайдено у audio/` у консолі.

### Усе чорне / сповільнено

1. Перевірте, чи увімкнене апаратне прискорення в браузері (`chrome://gpu`).
2. Занадто багато пелюсток → зменште `SCENE.particles[0].count`.
3. Занадто багато пилу → зменште `SCENE.dust.count`.
4. Тіні → вимкніть `SCENE.lights.sun.castShadow = false`.

### Полароїд показує білий прямокутник замість фото

Фото не завантажилось. Див. «Фото не з'являється».

### Сторінка не перегортається

1. Перевірте, що `state.mode === 'reading'` (у консолі: `__dbg.state.mode`).
2. Перевірте, що не залипли `state.animating === true` або `state.drag !== null`.
